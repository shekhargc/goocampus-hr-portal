Speciality groups

Every speciality in the predictor data, grouped as Clinical or Non-clinical (Para-clinical / Pre-clinical where known). The group comes from the cut-off file's Clinical/Non-clinical column; only specialities the file doesn't cover fall back to name rules. Your speciality-type sheet takes priority over the file (matched by course name, else by subject — so DNB/NBEMS versions inherit it). Override any row here. This drives the College Predictor's optional Clinical / Non-clinical filter. Unclassified specialities are left out of both filters until you place them.
