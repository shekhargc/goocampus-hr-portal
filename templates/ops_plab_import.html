Import PLAB Clients from CSV

Upload a CSV exported from Zoho Creator. The importer will map columns automatically and skip duplicates (by registration number).

📁 Click to select or drag and drop your CSV file
Accepts .csv files only

Expected Column Names

Your CSV should contain these columns (column names must match exactly):

  • Candidate Name
  • Registration Number
  • Registration Date
  • Plan Type
  • Stage Joined
  • Account Status
  • Current Status
  • Package
  • Discount
  • Final Package
  • 1st-4th Installment
  • Email
  • Mobile
  • City
  • State

Import Tips

  • Duplicate Detection: Clients are identified by Registration Number. Existing clients with matching registration numbers will be skipped.
  • Name Parsing: Names in the format "Dr. FirstName LastName - GCUKIP/..." are automatically parsed correctly.
  • Currency Symbols: Currency values can include ₹ symbols and commas (e.g., "₹50,000"). These will be cleaned automatically.
