Upload Attendance Report

Upload the fingerprint attendance report (.xls) to import employee time logs.

Accepts .xlsx files in either format: the raw fingerprint device export or the formatted attendance table (Date, Emp Code, Employee Name, Shift, ...). Employee codes are automatically mapped.

How it works

1. Export the Daily Attendance Report (Detailed Report) from your fingerprint software as an .xls file.

2. Upload it here. The system will parse each day's records and match employee codes to your HR profiles.

3. If data for the same employee and date already exists, it will be updated with the new values.

4. View the imported data on the Time Log page.
