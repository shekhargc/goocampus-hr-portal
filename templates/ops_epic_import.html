Import EPIC Registrations

Upload the EPIC Registration Status file exported from Zoho (CSV or XLSX). Existing records will be updated; new records will be added.

File: Epic Registration Status (R).csv or .xlsx

How it works

The registration number is extracted from the "Enter Candidate Name" column (text after " - "). Records are matched to existing PLAB clients by registration number. Existing records (same registration number) are updated with the latest data; new records are added.

Expected Columns

Enter Candidate Name, EPIC Registration, EPIC Status, Notary Camp, Registration Date, Documents Stage, Document Stage Status, Login ID, Login Pwd, Secret Question 1-4, Secret Answer 1-4, EPIC ID Number, Notary Camp Login, Notary Camp Password
