Import GMC Registrations

Upload the GMC Registration CSV exported from Zoho. The "Enter Candidate Name" column should contain the registration number (e.g. "Dr.Name - GCUKIP/24-25/036").

File: GMC Registration Form.csv

How it works

The registration number is extracted from the "Enter Candidate Name" column (text after " - "). Records are matched to existing PLAB clients by registration number. Duplicates (same registration number + GMC reference) are skipped automatically.

Expected Columns

Enter Candidate Name, GMC Reference Number, GMC Setup, Registration Date, License, License Received Date, Login ID, Login Pwd
